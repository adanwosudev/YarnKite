# YarnKite

YarnKite enables distributed, containerized application deployment with real-time processing and auto-scaling through a centralized orchestrator and scheduler.

With YarnKite, you get a lightweight tool that stays out of your way.

**What you get**

- YarnKite enables distributed, containerized application
- deployment with real-time processing and
- auto-scaling through a centralized orchestrator

## Key Features

- YarnKite enables distributed, containerized application

## Technology Stack

- rust
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/YarnKite.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
